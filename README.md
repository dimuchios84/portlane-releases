# Portlane

[![Support Portlane on Ko-fi](https://img.shields.io/badge/Support%20Portlane-Ko--fi-FF5E5B?style=for-the-badge&logo=ko-fi&logoColor=white)](https://ko-fi.com/dimuchio)

**A free, closed-source FTP, FTPS and SFTP client for macOS.**

Browse remote files, transfer them between your Mac and a server, and edit remote files in your preferred editor.

## What Portlane does

- Browse local and remote folders side by side.
- Connect using FTP, explicit TLS (FTPES), or SFTP over SSH.
- Upload and download files with a transfer queue.
- Open remote files in an external editor and upload saved changes.
- Create folders, rename, duplicate, and delete files.
- Store connection passwords in macOS Keychain.
- Use the interface in English or Russian.
